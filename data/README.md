# Research data

The core research-data snapshot is available in the private repository's
[2026-11-08 data release](https://github.com/subcoldzhang/antigen_epitope/releases/tag/data-core-2026-11-08).

See [the download and extraction guide](../docs/DATA.md) for the experiment-input archive,
SHA-256 checks, included directories, and known missing inputs. Extract the
archives at the root of the chosen data workspace to restore their original
relative paths.

This release contains data under `abdb_v3/pdb/`, `abdb_new_combine/data/`, and
`abdb_v4/fold_*/`. Historical SAbDab structures/tables under this root `data/`
directory and the approximately 80 GB generated OBJ mesh collection are excluded.
Existing source notebooks in this directory are retained.
